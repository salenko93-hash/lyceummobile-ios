# LyceumMobile iOS 1.0 — iPhone 14 Pro Max

**Нативний SwiftUI-проєкт** на основі LyceumTV **2.7.0.2 UID 81**.
Мінімальна версія: iOS 16.0. Інтерфейс адаптується до екрана iPhone 14 Pro Max.

## Готові можливості

- Головний екран: час і дата за Києвом, погода Кропивницького, обраний
  клас, поточний і наступний урок.
- 4 оригінальні офлайн-розклади: чисельник, знаменник і обидва розклади
  укриття. Збережено формати JSON Android-версії.
- Вибір класу 10-А…11-Г, дати, звичайного розкладу або укриття.
- Базова дата чисельника за замовчуванням `2026-08-31`;
  календар канікул з опційного `calendar.json`.
- Сумісність із чинним Google Apps Script: активні оголошення, події, заміни.
- HTTPS GitHub Raw / локальний HTTPS manifest із обов'язковою перевіркою
  SHA-256 **всіх чотирьох** JSON до активації нового комплекту.
  При збої залишиться попередня перевірена/вбудована копія.
- **Лише UID 81** alerts.in.ua, токен вводиться користувачем на iPhone і
  зберігається в Keychain, а не в GitHub чи вихідному коді.
  Відповіді A або P означають тривогу; N — підтверджений відбій.
  Мережева помилка **не** означає відбій, остання тривога зберігається.
- Перехід на екран укриття при підтвердженій тривозі та 15-секундний
  екран відбою після переходу A/P → N.
- Хвилина мовчання 09:00–09:01 Europe/Kyiv з 60 BPM метрономом,
  регулюванням гучності та 60-секундним тестом.
  Метроном припиняється при тривозі, виході з хвилини мовчання
  та переході застосунку у фон.

## Важливі обмеження iOS

**Це ще не встановлюваний .ipa.** Повний вихідний проєкт з Xcode-проєктом
готовий до першої хмарної збірки, але фактична збірка під iOS має пройти
на Mac (наприклад, через Codemagic). З Windows локально Xcode не запускається.

Перевірка alerts.in.ua відбувається **лише поки застосунок на екрані**.
Постійна фонова перевірка, push-повідомлення, завдання за розкладом
о 09:00 при закритому застосунку відсутні. Для таких push-повідомлень
потрібен окремий надійний сервер і Apple Push Notification service.
**LyceumMobile не є офіційною системою оповіщення про небезпеку.**

Публікація розкладів укриття у **публічному GitHub заборонена без
дозволу адміністрації**. Вихідний проєкт уже містить ці офлайн-дані,
тож для завантаження його на GitHub використовуйте **Private repository**.
Відкритий GitHub Raw для оновлень також не підходить для службових
розкладів: за таких умов потрібен доступний авторизованим користувачам
HTTPS-сервер. У цій версії віддалені файли за HTTPS завантажуються
без токенів автентифікації.

## Старт із Windows — рекомендована послідовність

1. Розпакуйте повний ZIP у звичайну папку.
2. На https://github.com/new створіть **НОВИЙ PRIVATE** репозиторій,
   наприклад `lyceummobile-ios`, **без початкового README**.
   **Не** завантажуйте цей повний iOS-проєкт у публічний репозиторій
   `lyceumtv-updates`: тут вбудовані розклади укриття.
3. У PowerShell відкрийте папку `LyceumMobile-iOS-1.0`.
   Якщо git відсутній: `winget install --id Git.Git -e`, потім
   перезапустіть PowerShell. Далі:

```powershell
git init
git add .
git commit -m "LyceumMobile iOS 1.0"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/lyceummobile-ios.git
git push -u origin main
```

Авторизуйтеся через браузер Git Credential Manager. Не записуйте
Apple-ключі й alerts.in.ua токен у репозиторій.

4. У https://codemagic.io підключіть свій приватний GitHub-репозиторій.
   На сторінці застосунку ввімкніть конфігурацію `codemagic.yaml`
   та оберіть **`ios-compile`**. Це спочатку перевірить Swift-тести й
   збиратиме iOS застосунок **без підпису**. Непідписаний .app
   **не встановлюється на iPhone**.
5. Для встановлення на iPhone і TestFlight потрібні
   **Apple Developer Program** та налаштування підпису.
   Зареєструйте у Apple Developer bundle ID
   `ua.edu.cunl.lyceummobile` (або змініть його і в .pbxproj,
   і в `codemagic.yaml`), створіть ключ App Store Connect.
   У Codemagic створіть інтеграцію з точною назвою
   **`LyceumMobile_AppStore`**, налаштуйте iOS certificates / profiles
   для того самого Bundle ID. Тоді запускайте **`ios-testflight`**.
   Після успішної підписаної збірки можна ввімкнути
   публікацію у TestFlight через Codemagic.
6. На iPhone після встановлення відкрийте Налаштування:
   уведіть токен alerts.in.ua (UID 81), URL чинного Google Apps
   Script `/exec` та URL GitHub Raw `content_manifest.json`,
   встановіть базовий понеділок і клас. Виконайте «Синхронізувати».
   Оновлення розкладів дозволено тільки після актуального
   підтвердження, що немає тривоги.

Докладніше див. `WINDOWS_TO_IPHONE.md`.

## Перевірки

```bash
swift test --jobs 2
python3 tools/validate_data.py
```

Ці перевірки не замінюють повної iOS-збірки на Mac та тестування
на справжньому iPhone. Після успішної хмарної збірки перевірте
фактичний звук 60 BPM та поведінку у режимі тиші iPhone.
